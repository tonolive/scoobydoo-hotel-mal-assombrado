# Scooby doo Hotel Mal Assombrado

Jogo de boardgame o qual os jogadores deverão em cada turno fazer alguma ação de personagem da turma do Scooby em que cada personagem faz uma ação diferente,
sendo o objetivo do jogo ou chegar até o final da trilha se você for um funcionário do hotel ou revelar quem é o fantasma.

O jogo também termina se a trilha do fantasma chegar no fim, dando a vitória para os fantasmas.


# Funcionalidades

- Adicionar a quantidade de jogadores (4 - 8).
- Distribuir os papeis de funcionário e fantasma.
- Distribuir a quantidade de cartas de aventura para cada jogador.
- Realizar o turno individual de cada jogador.
- Fazer a ação do jogador.
- Subir na trilha.
- Suspeitar de um jogador.
- Votação
